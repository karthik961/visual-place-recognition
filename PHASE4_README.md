# Phase 4 — Evaluation and Analysis

Built for the existing [visual-place-recognition](https://github.com/karthik961/visual-place-recognition) repository. **Do not make a new nested project folder.** Put `run_phase4.py`, `test_phase4.py` and `requirements_phase4.txt` alongside `run_phase3_corrected.py` in the *root* of your existing repository.

## Run

```bash
cd ~/CS_682/Project/cs682-vpr
# Copy the 3 Phase 4 files here first, if not already in this folder.
python -m pip install -r requirements_phase4.txt
python -m unittest test_phase4.py -v
python run_phase4.py
```

Prerequisites:
- `data/GardensPoint/{day_left,day_right,night_right}/Image000.jpg` through `Image199.jpg` (600 JPEGs)
- `results/phase2_embeddings.npz` (generated by `python run_retrieval.py`, intentionally not committed)
- Existing `run_phase3_corrected.py` and `src/orb_geometry.py` from Phase 3

If the dataset is stored elsewhere, pass `--data-dir /path/to/GardensPoint`. If embeddings are elsewhere, pass `--embeddings /path/to/phase2_embeddings.npz`.

## Experiment design

- Reference gallery: 200 `day_right` images.
- Query sequences: 200 `day_left` and 200 `night_right` images.
- Top-10 candidates from saved normalized ResNet18 embeddings; rerank only those candidates.
- Recall@1/5/10 with approximate ±2 index matching, **not exact GPS ground truth**.
- Phase 3 reference: bonus 0.05; >=8 inliers; >=0.2 inlier ratio; inlier scale 30; fixed alpha 0.7.
- Sensitivity: bonus `{0, .01, .025, .05, .075, .10}` × minimum inliers `{4,8,12,20}` × minimum inlier ratio `{.1,.2,.3}` = 72 configurations.
- Development query indices 0–99, retrospective evaluation indices 100–199, for *each* sequence. The *same* configuration is chosen to maximize the mean daytime/nighttime development Recall@1; development Recall@5 and proximity to Phase 3 defaults break ties. The selected config is evaluated once on the retrospective evaluation queries and on the full set. The fixed and original Phase 3 methods are also reported.

### Scientific limitations — include in final report

Earlier Phase 3 performance on **all 400 queries** was already inspected and used to revise the scoring formula. Therefore the retrospective split in Phase 4 is **not an independent/blinded held-out test**, even if the Phase 4 parameter selector itself only reads the development subset. Also, the split uses contiguous frames from the same route, all share the same reference gallery, and the ±2 rule approximates rather than guarantees place identity. Report the experiment as retrospective sensitivity analysis and provide independent-dataset validation if available.
